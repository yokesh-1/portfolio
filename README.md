
# Yokesh | AI Full Stack Developer

A personal portfolio showcasing AI-powered applications, full-stack projects, technical skills, and professional experience.

## ✨ Features

- Modern, responsive dark-themed design
- Animated hero section
- About, skills, and experience sections
- Project showcase with technology tags
- Contact and resume links
- Social media integration

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- SVG Icons

## 🚀 Getting Started

```bash
git clone <your-repository-url>
cd <your-project-folder>
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.
